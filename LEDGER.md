one commit per ledger entry, with regenerated goldens and the expected output
change documented in the commit.

## Type-polymorphic idiom inventory (audit, 2026-08-31)

Entries #33-#39 came out of a sweep for base-R functions whose *semantics*, not
just their result, change with the type/length/shape of the argument. The
remaining sites are latent — each is unreachable today for a stated reason — but
they are the same hazard and are recorded so a future change does not
un-guard one silently. Verified in the pinned env:

| call | result |
|---|---|
| `diag(m)`, `m` q x q | length-q diagonal (the intended use) |
| `diag(m)`, `m` q x 1 | **first element only**, silently |
| `diag(v)`, `v` length q > 1 | q x q diagonal **matrix** |
| `diag(x)`, `x` length-1 numeric < 1 | **0 x 0 matrix**; `sum()` is `0` |
| `diag(x)`, `x` length-1 numeric >= 1 | `trunc(x)` x `trunc(x)` **identity** |
| `sample(x, n)`, `x` length 1 | samples from `1:x`, **not** from `x` |
| `1:n`, `n == 0` | `c(1, 0)` — the loop runs twice, backwards |
