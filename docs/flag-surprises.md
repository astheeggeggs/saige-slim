## 4. THE PATTERN

Eleven of the thirteen are one shape: **the guard tests a proxy one level away from the quantity it protects, and the proxy is the thing that was easy to reach at that point in the code.** `--flexRV_lofAnno` is checked against the union of labels in the *file* rather than the masked marker set actually tested (F6); the duplicate-weight-set guard compares *names* rather than the weight vectors, while `skatoDedupe` proves the identity at run time three functions later (F12); the explicit-max-MAF detection greps *argv* rather than asking optparse what it parsed (F9); the format-exclusivity test looks at the two *primary* files rather than all six (F10); LOCO selects on `is.numeric(chrom)` rather than on the `isLOCO` flag step 1 wrote (F7); the fam reader pushes an IID with no uniqueness test while the phenotype reader and the psam reader both refuse the same input by name (F3); the fastTest exemption keys on `MAC > MACCutoffforER` as a proxy for "ER will answer this", which is false for 23 of 25 bundled markers (F4); and the `mac:` kernel is compared against an absolute threshold with no reference to the `2N·maxMAF` ceiling the ingest already imposes (F5) — that is the "guard predicates resting on accidents" failure repeated in nine places. Two consequences compound it. First, **this branch's new disclosure machinery counts rows emitted, not cells intended**, so every one of these is invisible to it *by construction* — `rec.rows = rec.combined = nonMissingPvalVec.n_elem` with the comment saying why, `g_burdenAsked += burdenTested.size()`, `interesting` false whenever nothing was refused — and in five findings the log actively reassures ("every one a plain Cauchy combination of every cell tested", "FlexRV: 192 transform sets", `print(opt)` showing the discarded value, "will be calculated via effecient resampling", "only pval_cutoff_for_fastTest changes which regions pay it"). Second, **the marker path got the fix and the region path did not**, three separate times: the S9 byte count and its DUPLICATED warning (F2), the escalation option (F11), and the trait-gated re-test (F4 is the marker-path mirror image). The cheapest systemic repairs are therefore (a) make the disclosure sidecar count *intended* cells, not written rows — it would have caught F5, F6 and F12 without a single new guard — and (b) re-run each of the nine proxy guards against the quantity it is standing in for.
