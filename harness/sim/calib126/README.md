markers summed, except the ultra-rare ones (MAC <= 10), which enter as the
per-sample MAX of their genotypes (the collapse); the plain allele sum is off by
the co-carrier count on 387 of 1,875 gene cells. `predicted_cell_mac_collapsed.tsv`
is that table for the gene file; the windowed one is regenerated by the script.
